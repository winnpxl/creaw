# Creaw: studio website

Marketing site for Creaw, a design & development company.
Stack: Next.js (App Router, `src/`), React, Tailwind v4, TypeScript.

## Workflow
- Build from the references in `design-reference/`, then refine based on taste feedback.
- Design tokens (colors, fonts) live in `src/app/globals.css` under `:root` / `@theme`.
- Current homepage copy and work items are placeholders.
